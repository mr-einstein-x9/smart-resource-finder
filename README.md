# Smart Study Resource Finder
A streamlit based web app which help to find curate learning resources based on subject,level and preferred language.
---

## Live demo
☝️👉[https://mr-einstein-x9-smart-resource-finder-app-9cit3k.streamlit.app/]
---

## Problem 
Students often waste time in searching for quality resources which are scattered all over the internet.
This web app "Smart Study Resource Finder" filters out source based on user preference and collect them in one place.
---

## Features :
-✅ Subject wise filtering            
-✅ Level based recommendation                    
-✅ Language preference            
-✅ Curated high quality resources          
-✅ resource discription                        
-✅ Clean streamlit UI            
---

- **Python**
- **Streamlit**
